# MongoDB

Owned by the API/data team. Database container definition and seed data
for the `EchoNet` database.

- `MongoDB.Dockerfile` — Mongo container build.
- `init/` — database initialization/seed scripts.
- `test_connection.py` — quick manual connectivity check.
- `docker-compose.yml` — standalone Mongo-only compose (see `src/deployment/docker/docker-compose.yml` for the full stack).
