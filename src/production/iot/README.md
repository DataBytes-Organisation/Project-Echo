# IoT

Owned by the IoT/edge team. Sensor node and edge-inference clients that
capture audio and forward it to the API.

- `edge_inference/` — on-device inference client.
- `management_application/` — current sensor management/upload client.
- `2025_t3_prototype/`, `2026_t1_new_onboarding/` — active onboarding/provisioning work.
- `previous_implementation/` — superseded client/server implementation, kept for reference.
