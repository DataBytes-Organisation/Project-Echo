# HMI (Human-Machine Interface)

Production Express dashboard for Project Echo live detections, map views,
sensor health, payments, and admin pages.

## Layout

- `ui/` - deployable Node.js package and static browser UI.
- `HMI.Dockerfile` - production image for the `ui/` package.
- `ai/` - reference spreadsheets used by dashboard content.
- `digital_assets/` and `recodings/` - media assets used by the UI.

## Local Operation

Run the HMI from the deployable package:

```powershell
cd src/production/hmi/ui
npm ci
npm test
node server.js
```

The HMI listens at `http://localhost:3000` and proxies Backend requests to
`API_HOST`/`API_PORT` from the environment. The production Docker build runs
`npm ci --omit=dev` before starting `node server.js`.

`node_modules/` is generated by npm and ignored by Git. Do not track generated
dependencies; use `package.json` and `package-lock.json` as the dependency
contract.
