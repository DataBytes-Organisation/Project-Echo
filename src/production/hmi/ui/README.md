# Project Echo HMI

This directory is the deployable HMI package. It runs one Express server that
serves static browser pages and same-origin API routes. Server code uses
CommonJS. Browser code under `public/` uses ES modules.

## Setup

Use Node.js 22 and npm 10 from this directory:

```powershell
cd src/production/hmi/ui
npm ci
npm test
node server.js
```

Open `http://localhost:3000` or `http://localhost:3000/login`.

`node_modules/` is generated by `npm ci` and ignored by Git. Do not document or
commit generated dependencies as source files. Docker installs production
dependencies with `npm ci --omit=dev` and starts `node server.js`.

## Environment

Copy `.env.example` to `.env` for local overrides. The common local values are:

```env
API_HOST=localhost
API_PORT=9000
CLIENT_URL=http://localhost:3000
COOKIE_SECRET=replace-with-a-long-random-value
```

The HMI defaults to port 3000. Backend, Redis, MongoDB, email, and payment
settings are read from environment variables by `server/config/environment.js`
and the route modules.

## Structure

```text
ui/
|- server.js                  Express bootstrap
|- server/                    CommonJS app, config, middleware, routes, services
|- public/
|  |- pages/                  HTML pages served by legacy-compatible routes
|  |- features/               Feature-owned browser modules and styles
|  |- shared/                 Shared browser HTTP, UI, and admin shell modules
|  |- assets/                 Static fonts, images, and styles
|  `- vendor/                 Vendored browser libraries
`- tests/
   |- browser/                Browser-module and static-dependency tests
   |- server/                 Express route and server-module tests
   `- structure/              Package, layout, and removal-audit tests
```

## Tests

```powershell
npm test
npm run test:node
npm run test:jest
node --test tests/structure/package-hygiene.test.mjs
```

`npm test` runs the Node test phase first and then the Jest phase.
